CÁCH GHÉP
1. Dùng Canvas 1600×900 và quy tắc anchor trong Docs/02_GHEP_21_MAN.txt.
2. Thêm node theo đúng thứ tự bảng bên dưới; node sau vẽ trên node trước.
3. parent trống = ArtKitStage; parent có giá trị = trong Content/group có tên đó.
4. Khung/nút: Image Sliced, viền theo importer; icon/art: Image Simple + Preserve Aspect.
5. Các node label dùng UI Text; button dùng Image + Button + child Text; bar dùng track + Image Filled.
6. Action screen:* là navigation xem thử; game:* cần nối controller. Dữ liệu số trong file là ví dụ.
